# BƯỚC 151.20 – XEM TRỰC TIẾP FILE

Phạm vi: chỉ module File.

- Ảnh: xem trực tiếp + tải xuống.
- PDF: xem trực tiếp + tải xuống.
- Word (.doc/.docx), Excel (.xls/.xlsx), PowerPoint (.ppt/.pptx): xem trực tiếp trong modal bằng Microsoft Office Online Viewer + tải xuống.
- Text/CSV/JSON/XML/MD/LOG: giữ xem nội dung + tải xuống.
- Không thay đổi database, RLS, Auth hay các module khác.
- Không cần SQL.
- Cache script: 151200.

Lưu ý: Office Online Viewer cần Internet và URL file phải truy cập được từ dịch vụ Microsoft. Project hiện dùng public URL Supabase Storage cho file.
